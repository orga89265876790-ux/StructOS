# StructOS — мобильный лендинг

Рабочая мобильная landing page StructOS, собранная по утверждённому master reference.

## Возможности

- три адаптивные компоновки: мобильная, планшетная и компьютерная;
- автоматический выбор подходящего изображения здания через `picture`;
- Light/Dark Mode;
- анимированный логотип и свечение `OS`;
- световой импульс здания от фундамента вверх;
- последовательное свечение карточек «Проект → Договор → Смета»;
- выбор файлов с устройства;
- сетка статистики 2 × 2;
- поддержка `prefers-reduced-motion`.

Сайт полностью статический, автоматически перестраивается под ширину экрана и публикуется через GitHub Pages.
