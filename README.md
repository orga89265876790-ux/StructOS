# StructOS — мобильный лендинг

Рабочая мобильная landing page StructOS, собранная по утверждённому master reference.

## Возможности

- адаптация под экраны 320–430 px;
- Light/Dark Mode;
- анимированный логотип и свечение `OS`;
- световой импульс здания от фундамента вверх;
- последовательное свечение карточек «Проект → Договор → Смета»;
- выбор файлов с устройства;
- сетка статистики 2 × 2;
- поддержка `prefers-reduced-motion`.

Сайт полностью статический и может публиковаться через GitHub Pages без сборки.
