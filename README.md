# StructOS — мобильный лендинг

Рабочая мобильная landing page StructOS, собранная по утверждённому master reference.

## Возможности

- три адаптивные компоновки: мобильная, планшетная и компьютерная;
- автоматический выбор подходящего изображения здания через `picture`;
- Light/Dark Mode;
- анимированный логотип и свечение `OS`;
- световой импульс здания от фундамента вверх;
- последовательное свечение карточек «Проект → Договор → Смета»;
- загрузка до трёх файлов одновременно: один проект, один договор и одна смета;
- поддержка документов, изображений, скриншотов и камеры;
- обязательное название объекта, замена и удаление файлов;
- демонстрационное окно параллельного анализа с фоновым режимом;
- адаптивный экран результата и перекрёстное сравнение документов;
- пять языков интерфейса: RU, EN, TJ, KG и TR;
- вход и регистрация в шапке как подготовленные точки подключения;
- бесшовная бегущая лента доверия;
- установка StructOS как PWA с инструкциями для Safari, Chrome и Яндекс Браузера;
- сетка статистики 2 × 2;
- поддержка `prefers-reduced-motion`.

Сайт полностью статический, автоматически перестраивается под ширину экрана и публикуется через GitHub Pages. Реальный серверный анализ документов и авторизация подключаются отдельным этапом; текущий поток анализа является интерфейсным прототипом.
